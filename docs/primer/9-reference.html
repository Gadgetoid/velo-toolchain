What Each ROM Has

A selection of functions people reach for, checked against the export lists in exports/. A blank cell means the ROM doesn't export it, so a program that calls it won't compile for that version.

Microsoft's SDK headers covered some gaps with macros: DialogBoxParamW, and on CE 1.0 SetDlgItemTextW, GetDlgItemTextW and SendDlgItemMessageW, are built from the functions that are exported. Some functions are exported without the W, such as GetVersionEx and FindResource, though they take wide strings. The toolchain's headers accept either name.

What the headers declare

The toolchain's headers are CeGCC's w32api, patched so constants, structures and signatures match Microsoft's CE 1.0 and 2.0 SDKs. windows.h gives the API as the target version has it, with the C runtime's wide string functions and the object store databases. commctrl.h, commdlg.h, winsock.h and the others add their parts. A function the target ROM doesn't export is marked unavailable, so using it is a compile error that names the version.

Not covered: COM and OLE, telephony, drivers and kernel internals, the address book and mail APIs, and ANSI (A) structures. The toolchain's README.md has the full list. For those, check the export list and declare what you need yourself, with WINAPI.

Glossary

Accelerator
A shortcut key, mapped to a command ID by an ACCELERATORS resource.
Command bar
CE's combined menu bar, toolbar and title bar, at the top of a program's window.
Common controls
The controls in commctrl.dll: list view, tree view, tabs, progress bar, trackbar, up-down, toolbar, status bar. Call InitCommonControls before using them.
Device context (DC)
A drawing surface with its current font, pen, brush and colours. HDC.
Dialog units
The coordinates in dialog resources, which scale with the dialog's font.
GDI
The drawing part of Windows: device contexts, fonts, pens, brushes and bitmaps.
Handle
An opaque value naming something the system owns: HWND, HFONT, HANDLE.
Instance
A loaded program or DLL, HINSTANCE. Needed to load its resources and register its window classes.
Object store
CE's storage in battery-backed RAM: the file system, the registry and databases.
Resource
Data built into the program from a .rc file: menus, dialogs, icons, bitmaps, strings, accelerators.
Window class
A name plus a window procedure and defaults, registered with RegisterClassW, that windows are created from.
Window procedure
The function that handles a window's messages.
_WIN32_WCE
100 when building for CE 1.0, 200 for CE 2.0.
