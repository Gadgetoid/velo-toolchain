The Velo CE Primer Programming Windows CE 1.0 and 2.0 on the Philips Velo 1

Includes six example programs and screenshots

A beginner's guide for competent programmers: from an empty folder to windows, dialogs, sockets and two real projects, built on your Mac with velo-toolchain and tested in velo-emu.

What's Inside

Each chapter builds on the last, but the later ones work as a reference too. If you've written Win32 programs before, skim chapters 1 to 3 for the parts marked as different on CE.

  1. Meet the VeloThe hardware, Windows CE 1.0 and 2.0, and how CE differs from the Windows you know.
  2. Toolchain and EmulatorInstall, build your first program, run it in velo-emu, debug it with GDB and VS Code.
  3. Win32 in a HurryWinMain, the message loop, window procedures, painting, the pen and the keyboard.
  4. Screen Layout CookbookFive layouts with screenshots: two panes, list and details, a dialog, tabs and controls, custom drawing.
  5. Strings, Memory, Files and the RegistryLife without a C library, Unicode, the object store, cards, settings, processes and DLLs.
  6. Networking and ThreadsWinsock, HTTP through the proxy, worker threads and talking to the user interface safely.
  7. Project: A Bluesky ClientThe AT Protocol calls, sessions, JSON, pictures and how velo-bluesky fits together.
  8. Project: An App StoreCatalogues, downloads, installing, shortcuts, uninstalling and free space.
  9. ReferenceWhat exists on CE 1.0 and 2.0, messages, gotchas, a glossary and further reading.

Before You Start

You'll need a Mac or Linux machine with these, all covered in chapter 2:

  • velo-toolchain (this repository) with Homebrew's llvm, lld and cmake.
  • A built velo-emu checkout and its ROMs, to run what you build.
  • Optionally Homebrew's gdb and VS Code with the C/C++ and CMake Tools extensions, for debugging.

You should be comfortable with C: pointers, structs, function pointers and building with CMake. You don't need to know anything about Windows.

How to Read This Book

Code you can type or copy is printed on green-bar paper. The label at the top says which file it's from:

@source examples/hello/hello.c

Listings marked with a file name are copied from that file in the repository, as it was when this primer was written. Names in this style are functions, messages, files and settings. Keys look like Ctrl+N.

Velo Tip

Boxes like this one point out where Windows CE, or the Velo, behaves differently from desktop Windows or from what you'd guess. Most of them were found the hard way, in the emulator, while writing this book.

Screenshots come in pairs, CE 1.0 on the left with its four greys and CE 2.0 on the right with sixteen, taken from velo-emu's simulated LCD. To make them again:

make primer-screenshots

That needs the same settings as make test, listed in the repository's README.md. The example programs are in docs/primer/examples, and build with:

make primer
